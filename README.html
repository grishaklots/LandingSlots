Flight Slot Allocation

Quick start · Open the application

  1. Choose a month. Use the calendar arrows. Distribution applies to the displayed month.
  2. Add time slots. Enter a date as DD/MM/YYYY, From and To in 24-hour format, and the airport/runway. Click Add slot. From automatically sets To one hour later; adjust it as needed. Slots must end on the same date.
  3. Add students. Enter each student's name in the roster and click +.
  4. Add upvotes. Open a calendar slot and click the student chips on the left. Lit chips indicate upvotes; click again to remove one. The grid below is a read-only summary.
  5. Compute assignments. Click COMPUTE FAIR DISTRIBUTION. The system prioritizes students with fewer assignments, then fewer monthly upvotes. Existing manual assignments remain locked.
  6. Adjust manually. Open a slot, turn on Enable force assignment, choose any student, and click Force assignment. An upvote is not required. The green Assigned tag identifies the current pilot.

Changes save automatically in this browser. Upvote edits do not reassign slots until you compute again. Use Clear assignment in a slot to release it, or the top-level CLEAR ASSIGNMENT button to clear assignments across all months after confirmation. Both preserve upvotes.

Export data downloads a JSON file containing all students, slots, upvotes, and assignments across every month. To restore it, click Import data, choose the file, review the summary, then click Replace workspace. Import replaces existing data rather than merging it; export first to keep a backup. Dates and times are kept as entered. No files are uploaded.
